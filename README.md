# Liquid War Drones

**Пошаговая артиллерия на летающих островах, где у каждого куска земли своя гравитация.**
*A turn-based artillery game on floating islands where every chunk of soil has its own gravity. Runs in a phone browser, single HTML file.*

### ▶ [Играть в браузере](https://buhjir.github.io/LIQUID-WAR-DRONES/)

Один файл, без установки. Сделано под телефон: два стика, рычаги, тач-управление.

---

## Что в ней особенного

**Нет общего «низа».** Острова висят в пустоте, и каждый тянет к себе собственной массой. Рядом с островом ты прижат к его поверхности, сверху или снизу. Вдали все острова тянут разом, и снаряд летит по изогнутой траектории между ними.

**Земля — это масса.** Взрыв выбрасывает грунт, грунт падает на другой остров, и поле тяготения пересчитывается вслед за ним. Остров, с которого содрали землю, начинает тянуть слабее. Поле лежит на сетке 4 м и обновляется инкрементально: пересчитываются только блоки, где поменялась масса.

**Жидкости настоящие.** Вода, нефть, лава, пар, дым и огонь — это частицы LiquidFun (Box2D) в WebAssembly. Огонь всплывает на воде, лава течёт, пар поднимается против поля.

**Свет — это оптика.** Лазер-резак преломляется по Снеллу, отражается по Френелю и рассеивается в облаках. Видимость зависит от погоды и времени суток, а разведку ведут дроны и наблюдатель.

## Устройство репозитория

```
index.html        ← актуальная игра (v1.0). Единственный файл, его отдаёт GitHub Pages.
src/              ← исходники ранней версии (до v1.0), по модулям
shell.html        ← разметка, CSS и HUD для сборки из src/
wasm.js           ← LiquidFun 7.0.0 в base64
build.py          ← сборка src/ → build/liquid-war-drones.html
t/                ← автотесты на Playwright (сценарии боя, ИИ, гравитация, лазер)
```

### Важно про версии

`index.html` и `src/` — это **разные версии** игры.

- **`index.html` (v1.0)** — финальная версия. Вся симуляция (мир LiquidFun, логика, ИИ, отрисовка) работает в Web Worker на отдельном ядре, а главный поток только применяет изменения DOM, играет звук и передаёт касания. Здесь же якорь, перископ субмарины, управление подъёмом и сохранение журнала боя. Код не минифицирован и снабжён комментариями: файл и есть исходник, читать его можно прямо так.
- **`src/` (v0.7)** — модульные исходники до переноса в Worker. `python3 build.py` собирает из них рабочую, но более раннюю версию игры.

### Сборка и тесты

```bash
python3 build.py              # → build/liquid-war-drones.html
```

Тесты в `t/` писались под конкретное окружение: в них зашиты пути к Chromium и к собранному файлу. Чтобы запустить их у себя, поменяйте эти пути.
