# Liquid War Drones — исходники

Сборка: `python3 build.py` → склеивает `src/*.js` по порядку имён, вставляет
в `shell.html` (метка `/*@@JS@@*/`) вместе с `wasm.js` (LiquidFun WASM в base64).
Результат: `/mnt/user-data/outputs/liquid-war-drones.html` — поменяй путь в build.py под себя.

- `shell.html` — разметка, CSS, HUD (тач-геймпад), диалоги
- `wasm.js` — `const WASM_B64 = "..."` (Box2D/LiquidFun 7.0.0)
- `src/01_core.js` — утилиты, реестры, настройки, качество
- `src/02_data.js` — масштаб SC, архипелаги (карты = списки островов), погода, материалы, фигуры из блоков, апгрейды, ИИ-профили
- `src/03_audio.js` — музыка и звуки (WebAudio)
- `src/04_world.js` — мир, острова (build из списка островов), тектоника (displace/deposit/scorch), вода, системы частиц
- `src/04b_grav.js` — гравитация островов: поле 2D-Ньютона на сетке 4 м, инкрементальное обновление при переносе грунта, силы на тела и частицы
- `src/05_entities.js` — танк, субмарина, дроны (разведка, ударный), наблюдатель, блоки, FX
- `src/05b_nature.js` — камни, трава, выброс грунта, дым/облака
- `src/06_systems.js` — оружие, взрывы, огонь (всплывает на воде), свет, видимость, разведданные, акустика, разведка
- `src/06b_optics.js` — волновой лазер (Френель/Снелл, рефракция и рассеяние в облаках)
- `src/07_ai.js` — ИИ (для одиночной игры и тестов)
- `src/08_render.js` — отрисовка, прицелы, индикаторы дронов, баннер хода
- `src/09_game.js` — матч, ходы, заморозка и передача хода, ввод
- `src/10_ui.js` — иконки, стики, меню, диалоги
- `t/*.py` — автотесты Playwright (путь к Chromium внутри)
